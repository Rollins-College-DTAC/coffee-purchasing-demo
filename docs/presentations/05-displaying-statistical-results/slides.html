Displaying Statistical Results

Showing a test so that anyone can check it: formula, inputs, result, threshold, meaning

Raw Coffee Purchasing · reference project · simulated data only

Every chart in this lecture uses real numbers from the reference run of 2026-10-13. The statistics themselves are introduced from scratch; the focus is on how to show them honestly.

Learning objectives

2

3

A statistical test turns data into a number and compares it with a rule, so that a decision rests on evidence rather than a hunch.

A result is checkable only with all five parts

Formula

Meaning

Displaying Statistical Results · 3 / 11

Each part answers a question a sceptic would ask. Formula: what did you compute? Inputs: from what? Result: what came out? Threshold: compared with what rule? Meaning: so what? In the project, agent/stats.py returns exactly these five fields for every method, and log_stat saves them to stats_log.

Concept 2 · the 95% confidence interval

An average from a sample comes with a margin of error

A 95% confidence interval is a range built so that 95 of every 100 such ranges contain the true average. More data gives a narrower range.

mean ± t × s ÷ √n

Example 1 · everyday

An election poll: "52%, plus or minus 3 points". The true support is most likely between 49% and 55%.

Example 2 · the project

Brazilian coffee after 8 lots: $3.45 to $3.79 per lb. After 81 lots: $3.60 to $3.71. Same coffee, more data, tighter range.

Displaying Statistical Results · 4 / 11

Read the formula in words: the average, plus or minus a multiplier from the t distribution, times the spread, divided by the square root of the number of lots. The square root of n is why more data narrows the interval: four times the data halves the width. For 8 lots the multiplier t was 2.365.

Displaying Statistical Results · 6 / 11 · decision_log, reference run, imports in time order

Displaying Statistical Results · 7 / 11 · exponential smoothing on gold_import_stats, reference run

A confidence interval is about an average; a prediction interval is about one future value, so it is much wider. Here the band is wide, $4.45 to $6.29, because each import mixes different origins and its average jumps around. Showing that width is honest: a single line would suggest a precision the data do not support.

Concept 5 · the backtest

Report it honestly when the simple guess wins

$0.44

Forecast's average miss per lb on the last 10 imports (7.8%)

$0.38

Average miss of the naive guess, "same as the last import"

A backtest hides recent data, forecasts it, and measures the mean absolute error (MAE): the average size of the misses.

Everyday: checking last week's weather forecasts against what happened.

Project: the dashboard prints "the baseline wins; the model adds nothing yet."

Displaying Statistical Results · 8 / 11 · stats_log backtest_mae, reference run

This is the most important slide of the lecture. A forecast that cannot beat "same as last time" should not be trusted, and saying so is part of the analysis, not a failure. Hiding this result would mislead the buyer. The likely cause is the mix of origins in each import; forecasting price per origin is a sensible next step.

Concept 6 · precision and recall

Grade the alarm, not only the data

Recall

1.00

Of the real anomalies, the share that were held. Every seeded anomaly was caught.

Precision

0.38

Of the held imports, the share that were real anomalies. 5 false alarms, most in the first 21 imports.

Everyday: a smoke alarm with perfect recall never misses a fire; one with poor precision also goes off for toast.

Project: early imports gave too little history, so the minimum was raised from 10 to 30 imports before testing.

Displaying Statistical Results · 9 / 11 · scripts/score_trigger.py against generator_log.csv

Because the data are simulated, the generator's log records which imports were seeded anomalies: an answer key for the trigger. Precision equals true positives divided by everything flagged; recall equals true positives divided by everything real. Show both, since either alone can be gamed: holding every import gives perfect recall and terrible precision.

A maths teacher gives no marks for "42" alone; the working shows how you got there and where it went wrong.

Displaying Statistical Results · 10 / 11 · dashboard/pages/analytics.py

Check the arithmetic live with the class: 2.365 × 0.197 ÷ √8 = 2.365 × 0.197 ÷ 2.828 = 0.165. So the interval is 3.62 ± 0.16, from $3.45 to $3.79, matching the earlier slide. Anyone can now verify the chart without trusting the code.

Check your understanding

Three questions

  1. An import averages $5.80/lb; recent imports average $5.20 with s = $0.15. Compute z. Is it held?
  2. Two origins' 95% intervals are $4.40–$4.70 and $4.60–$4.90. What can you conclude, and what would help?
  3. A classmate's dashboard shows only "Forecast: $5.37". Name two things missing.

Displaying Statistical Results · 11 / 11

Answers. 1: z = (5.80 − 5.20) ÷ 0.15 = 4.0, above 3, so it is held. 2: the intervals overlap, so we cannot be confident the averages differ; more lots would narrow both intervals. 3: any two of the prediction interval, the formula, the inputs, the backtest against the naive baseline, and a plain-language interpretation.
