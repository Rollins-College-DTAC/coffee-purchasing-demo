Streamlit Dashboards

Turning a Python script into a web page anyone can open

Raw Coffee Purchasing · reference project · simulated data only

The dashboard is the part of the project that people see: classmates, the instructor, and later an interviewer. This lecture explains how Streamlit builds it and how it reaches the web.

Learning objectives

By the end of this lecture you can

1

Explain how Streamlit turns a script into a web page, and why it reruns.

2

Identify the elements and pages of the project's dashboard.

3

Deploy it to the web with its secrets kept safe.

A dashboard is a single screen that summarizes data for decisions, like a car's dashboard summarizes speed, fuel and warnings.

Streamlit Dashboards · 2 / 9

No web development knowledge is needed. Streamlit hides HTML, CSS and JavaScript: you write Python, and it builds the page.

Concept 1 · a script becomes a page

Each Streamlit line draws one thing on the page

Example 1 · four lines

import streamlit as st
st.title("Coffee prices")
st.metric("Mean $/lb", "$5.15")
st.line_chart(prices)

A title, a big number and a chart, in that order, top to bottom.

Example 2 · the project

uv run streamlit run
streamlit_app.py

Opens the six-page dashboard in your browser at localhost:8501, reading the agent's SQLite database.

Streamlit Dashboards · 3 / 9

Streamlit is an open-source Python library. A function call such as st.metric both computes and displays, so a data analyst can build an interactive page without learning web programming. localhost means "this computer": the page is only visible to you until it is deployed.

Concept 2 · the rerun model

Any click reruns the whole script from the top

Streamlit does not patch the page. When someone presses a button or changes a choice, it runs the script again and redraws everything with the new state. Simple to reason about: the page always matches the code.

Example 1 · everyday

A spreadsheet: change one cell and every formula recalculates, so totals are never stale.

Example 2 · the project

if st.button("Release"):
decide(run_id, "release")

After the click the script reruns, and the held-import banner is gone.

Streamlit Dashboards · 4 / 9

Because everything reruns, slow work such as downloading the database is cached: in cloud mode the app keeps the downloaded data for 30 seconds instead of fetching it on every click. The button code is simplified from dashboard/pages/live.py, which also asks for the reviewer's name and, in the cloud, a passcode.

Seven building blocks make the whole dashboard

Like the gauges, warning lights and switches on a car dashboard, each element has one job.

Concept 4 · one page per question

Each page answers one question a person asks

A newspaper has sections so readers can go straight to sport or business. streamlit_app.py lists six pages in a side menu.

PageThe question it answers
Live runWhat is the agent doing now, and is anything waiting for me?
Models (MoE)Which model handled which task, why, and at what cost?
AnalyticsWhat do the statistics say, and how were they calculated?
DataWhat do the clean purchase lots look like, and how good is the data?
Pipeline historyHow long did each step take over recent runs?
GovernanceHow do the models score, what needs review, and what have we spent?

An airport departures board updates each flight's status by itself; nobody presses refresh.

A fragment, @st.fragment(run_every=5), reruns only the chart, colouring each step from run_log.

Streamlit Dashboards · 7 / 9 · simplified view of the Live run page

A fragment is a part of the page that reruns on its own, so the rest of the page, such as a half-typed reviewer name, is not disturbed. Each status is written in words as well as colour, so the chart still reads for colour-blind viewers. The real chart has more steps, drawn in two rows.

GH_TOKEN and APP_PASSCODE live in the app's Settings, then Secrets. The passcode guards Start demo, Release and Reject.

Streamlit Dashboards · 8 / 9

Three settings decide whether the deploy works: the file must be called streamlit_app.py at the repository's top level, the branch must be main, and Python must be set to 3.12 in the advanced settings. Packages install from uv.lock, so the cloud runs the same versions as the laptop. Every later push to main updates the app automatically, which is called continuous deployment.

Streamlit Dashboards · 9 / 9

Answers. 1: it reruns the script from the top; the release changed the database, so on the rerun the import is no longer held and the banner is not drawn. 2: st.metric for the number; st.expander holding st.code for the SQL and st.latex for the formula. 3: the URL names the wrong branch (master instead of main), or streamlit_app.py has not been pushed to GitHub yet.
