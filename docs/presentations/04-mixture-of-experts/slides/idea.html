Concept 1 · mixture of experts

Specialists plus a gate that picks one for each input

In machine learning, a mixture of experts combines specialist sub-models with a gate that sends each input to the right one (Jacobs et al., 1991). Large modern models use it so that only a few experts work on each word (Shazeer et al., 2017).

Example 1 · everyday

Hospital triage: a nurse sends a sprained ankle to the walk-in clinic and chest pain to the cardiologist. Nobody sees every specialist.

Example 2 · the project

The same idea across whole models: a router with readable rules sends sorting to Jev and number-finding to Claude.

Mixture of Experts · 3 / 9

Be precise with students: inside a large model the gate is learned, not written by hand, and nobody can read its reasons. The project borrows the idea at the application level, where the gate is plain rules a person can read and every choice is logged with its reason.
