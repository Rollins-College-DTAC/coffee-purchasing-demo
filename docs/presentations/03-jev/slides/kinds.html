Concept 1 · two kinds of model

A classifier chooses; a generative model writes

Classifier · Jev

Picks among answers you define, and gives a probability for each. It cannot invent an answer outside the list.

Everyday: a multiple-choice exam.

Project: "Container delayed at port" → logistics, from six categories.

Generative model · Claude

Writes new text. More flexible, but it can produce content the input does not support: a hallucination.

Everyday: an essay question.

Project: "price includes $0.25/lb freight premium" → writes 0.25.

Jev · 3 / 10

The project uses each for what it does best: Jev to sort and flag, Claude to pull out numbers and write explanations. A classifier's limited answer set is a safety feature: it cannot make up a price.
