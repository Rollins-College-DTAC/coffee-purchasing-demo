Jev

A model that answers multiple-choice questions, and says how sure it is

Raw Coffee Purchasing · reference project · simulated data only

Jev is made by TypeSafe and was released in limited early access in September 2026. In the project it reads every buyer's note and answers three questions about it. This lecture explains what kind of model it is, how to ask it questions, and how to judge its answers.
