Learning objectives

By the end of this lecture you can

1

Define a database, and say what problem it solves.

2

Distinguish a document database (TinyDB) from a relational one (SQLite).

3

Explain why the project keeps raw data apart from clean data.

A database is an organized store of data that a program can search, update and summarize, so the data survives after the program stops.
